# 📁 Projects

A collection of the projects featured on the **Projects** page of **zescott.com**. Each project lives in its own folder and can be opened independently, while this repository acts as the source for the portfolio's projects directory.

## Projects

| **Folder**       | **Description**                      |
| ---------------- | ------------------------------------ |
| `zsdev/`         | Desktop-inspired developer portfolio |
| `url-shortener/` | Browser-based URL shortener          |
| `wyr/`           | Would You Rather web game            |

More projects will be added over time.

## File structure

```text
projects/
├── zsdev/
├── url-shortener/
└── wyr/
```

Each folder is a complete standalone project containing its own source files.

## How to run

Clone the repository and open the project you'd like to view:

```bash
git clone https://github.com/ZacharyScottDeveloper/projects.git
cd projects
```

Then open any folder's `index.html` in your browser.

Or visit them by exploring the [Projects section of my website](https://zescott.com#projects).
